# 互動式股票技術分析儀表板

這是一個以繁體中文呈現的台股歷史行情分析網頁。使用者可以查看股票日線走勢、常見技術指標與近期交易資料，並匯出 CSV 報表。

## 功能

- 查詢台積電（2330）、聯發科（2454）、鴻海（2317）、元大台灣50（0050）、富邦金（2881），或輸入自訂台股代號。
- 選擇近 60、120 或 250 個交易日作為觀察區間。
- 查看收盤價、漲跌幅、區間高低價、成交量與 20 日均量。
- 以互動式圖表呈現 K 線、MA5、MA20、成交量及 RSI(14)。
- 查看最近 10 個交易日明細，並匯出所選期間的 CSV 報表。
- 手動重新查詢，或開啟每 60 秒自動重新查詢。

## 使用方式

開啟儀表板後選擇股票與觀察區間，系統會自動載入資料。也可以輸入自訂股票代號後按 Enter，或按「抓取真實數據」重新查詢。使用「匯出完整 CSV 報表」可下載目前所選股票與期間的資料。

## 資料來源與注意事項

行情資料透過 FinMind 公開 API 查詢台股歷史日線資料。這不是即時報價服務；每 60 秒自動更新代表重新查詢資料，不代表股價每 60 秒更新。

如果 API 無法取得資料（例如網路問題、無效代號或服務限制），儀表板會切換到模擬資料，並在頁面狀態列標示「備援模式：模擬數據」。模擬數據不代表真實行情，請勿用於投資決策。

MA 與 RSI 是用於觀察歷史價格趨勢的技術指標，不構成投資建議。
